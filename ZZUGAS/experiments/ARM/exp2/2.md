4. ARM 分支/跳转指令

绝对跳转指令说明：
- B：绝对跳转
- BL：绝对跳转 #imm，返回地址保存到 LR（X30）
- BLR：跳转到寄存器地址，返回地址保存到 LR（X30）
- BR：跳转到寄存器内容地址
- RET：子程序返回，默认返回地址在 LR（X30）

特殊、条件跳转指令说明：
- B.cond：cond 为真则跳转
- CBNZ X1, label：如果 X1 != 0 则跳转到 label
- CBZ X1, label：如果 X1 == 0 则跳转到 label
- TBNZ X1, #3, label：若位 X1[3] != 0，则跳转到 label
- TBZ X1, #3, label：若位 X1[3] == 0，则跳转到 label

条件选择类指令（A64 常见）：
- CSEL Rd, Rn, Rm, cond：cond 成立时 Rd = Rn，否则 Rd = Rm
- CSINC Rd, Rn, Rm, cond：cond 成立时 Rd = Rn，否则 Rd = Rm + 1
- CSINV Rd, Rn, Rm, cond：cond 成立时 Rd = Rn，否则 Rd = ~Rm
- CSNEG Rd, Rn, Rm, cond：cond 成立时 Rd = Rn，否则 Rd = -Rm
- CINC Rd, Rn, cond：cond 成立时 Rd = Rn + 1，否则 Rd = Rn
- CINV Rd, Rn, cond：cond 成立时 Rd = ~Rn，否则 Rd = Rn
- CNEG Rd, Rn, cond：cond 成立时 Rd = -Rn，否则 Rd = Rn
- CSET Rd, cond：cond 成立时 Rd = 1，否则 Rd = 0
- CSETM Rd, cond：cond 成立时 Rd = -1（全 1），否则 Rd = 0

5. 调用 C 语言函数 printf 输出信息的方法

```asm
.section .data
print_data:
.string "bigger data is:%d\n"
.section .text
mov x1, #100        // x1=要输出的数据；如果有多个数据，依次使用 x1...x7
ldr x0, =print_data // x0=字符串首地址
bl printf           // 调用 C 语言 printf 函数
// 详见实验三实验指导的 ARM 子程序调用机制
```
