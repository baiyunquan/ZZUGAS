## 2. 实验内容
1. 输出字符串 Hello, World!

### 2.1 创建 hello 目录
执行以下命令，创建 hello 目录，存放该程序的所有文件，并进入 hello 目录。

```bash
mkdir hello
cd hello
```

### 2.2 创建示例程序源码 hello.s
执行以下命令，创建 ARM64 汇编语言源程序 hello.s。

```bash
vim hello.s
```

录入信息显示程序：

```asm
.section .data // 数据区
msg: .string "Hello, World!\n" // 定义字符串
.section .text // 代码区
.global main // 主函数
main: stp x29, x30, [sp, -16]! // 保存 x29 和 x30
adr x0, msg // 获取字符串地址
bl dispmsg // 调用 dispmsg 显示
mov x0, 0 // 返回值
ldp x29, x30, [sp], 16 // 恢复 x29 和 x30
ret // 主函数返回
```

### 2.3 编译运行
保存示例源码文件，然后退出 vim 编辑器。在当前目录中依次执行以下命令，进行代码编译运行。

```bash
gcc -o hello hello.s libtest.a
./hello
```

3. GNU AS 常用汇编伪指令说明（学习通 3.6.4）
- 常量表示：
  - 十六进制数以 0x 开始，二进制数以 0b 开始。
  - 字符串常量如 "a"，字符常量如 'a'。
- 注释用 # 或 // 开头。
- 变量定义：
  - 变量名后面加 :
  - 伪指令前加 .
- 定义字节、字、双字和四字变量分别用 .byte、.word、.long、.quad。
- 字符串定义可以用 .string、.ascii（没有结束标志）或 .asciz（有 '\0'）。
- GNU AS 中没有 type、sizeof、lengthof 这类 MASM 风格伪指令。

4. 汇编程序框架

```asm
.text // 代码区
.global main // 主函数
main:
// 指令序列
ret // 主函数返回
```

7. ARM 通用指令（学习通 5.2.7，5.3.10，6.8）
- ARM 汇编指令语法通常形如：

```text
<opcode> <Rd>, <Rn>, <operand2>
```

- <opcode>：指令助记符，如 ADD。
- 条件执行：
  - 在 ARMv8 A64 中，通用数据处理指令不再像早期 ARM 那样普遍支持条件后缀。
  - 条件控制主要通过 B.cond、CSEL/CSINC 等指令实现。
- <Rd>：目标寄存器。
- <Rn>：第 1 个源操作数寄存器。
- <operand2>：第 2 个操作数（寄存器、立即数或带移位寄存器）。

8. 地址生成指令

### 3.8.1 获取 PC 相对地址指令
- ADR：获取标号相对于当前 PC 的地址。

```asm
ADR Xd, label   // Xd = label 的地址（PC + 偏移）
```

ADR 的编码范围约为当前 PC 的 ±1MB。

- ADRP：获取以 4KB 页对齐后的 PC 相对地址，常与 ADD 配合取完整地址。

```asm
ADRP Xd, label  // Xd = page(label)
```

其可覆盖更大范围（按页寻址，范围可达较大地址空间）。

### 3.8.2 载入地址伪指令
- LDR 伪指令写法：

```asm
LDR Xd, =label  // Xd = label 的地址（数值）
```

注意等号不可省略，否则是普通的 LDR 访存指令。

- 汇编器通常把常量/地址放入文字池（literal pool），再生成 PC 相对 LDR 指令去取值。
- 普通 LDR 指令例如：

```asm
LDR Xd, [Xn, #imm] // 从内存地址读取数据
```

9. STP 指令

stp 是 ARM 汇编中的成对存储指令（Store Pair），用于将两个寄存器值写入内存。

语法示例：

```asm
stp Xt1, Xt2, [Xn|SP, #imm]
stp Xt1, Xt2, [Xn|SP, #imm]!
stp Xt1, Xt2, [Xn|SP], #imm
```

示例：

```asm
stp x29, x30, [sp, -16]! // 将 x29 和 x30 入栈，并更新 sp
stp x2, x3, [x0, #16]    // 将 x2 和 x3 存入 x0+16 开始的内存位置
```

10. LDP 指令

ldp 是 ARM 汇编中的成对加载指令（Load Pair），用于一次从内存读取两个寄存器。

语法示例：

```asm
ldp Xt1, Xt2, [Xn|SP], #imm
ldp Xt1, Xt2, [Xn|SP, #imm]!
```

示例：

```asm
ldp x29, x30, [sp], 16 // 从栈顶读取 x29/x30，并将 sp 增加 16
```

11. BL 指令

bl 是 ARM 汇编中的子程序调用指令。执行 bl 时，会把返回地址写入 LR（x30），然后跳转到目标标签。

格式：

```asm
bl <target_label>
```

示例：

```asm
my_label:
...
bl my_subroutine
...
my_subroutine:
...
mov x0, #0 // 返回 0
ret        // 返回到 bl 后续指令
```
