# 实验三 子程序设计

## 1. 实验目的
理解子程序结构的特点，熟悉子程序参数传递的方法，掌握子程序的编写。

## 2. 实验内容
1. 编写子程序实现实验二的字符串复制功能，并编写验证子程序功能的主程序。
2. （可选）在 GDB 中调试自己编写的本实验要求程序，注意查看堆栈变化。

## 3. 实验指导
1. ARM 子程序设计（学习通 10.4）

```asm
// 子程序调用/返回示例
BL func // 调用子程序 func
...
func:
...
RET // 64 位程序的子程序返回
```

2. ARM 子程序调用机制
- 传递参数
  - 寄存器：X0-X7（SIMD/浮点参数用 V0-V7）
  - 栈：A64 没有 push/pop 指令，通常用 STP/LDP 实现成对压栈与出栈
- 返回值
  - X0-X7（SIMD/浮点返回用 V0-V7）
  - X8（结果地址，例如返回较大结构体时）
- 调用者保存寄存器：X9-X15，V16-V31
- 被调用者保存寄存器：X19-X29，V8-V15
- 返回地址寄存器：X30（LR）
- 帧指针（Frame Pointer）：X29（FP）
