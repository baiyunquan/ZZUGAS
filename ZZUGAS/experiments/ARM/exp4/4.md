# 实验四 与 C 语言的混合编程

## 1. 实验目的
熟悉模块连接和嵌入汇编生成可执行文件的混合编程方法。

## 2. 实验内容
1. 汇编语言调用 C 函数（返回两个 int 整数中的较大者）。
   - 比较函数：C 代码文件 compare.c。
   - 主程序：ARM 汇编代码文件 main.s。
2. C 语言调用汇编子程序（实验三字符串复制）。
   - 字符串复制子程序：ARM 汇编代码文件 strcpy1.s。
   - 主函数：C 代码文件 main.c。
3. C 代码中嵌入汇编代码（返回两个 int 整数中的较大者）。

## 3. 实验指导
1. C 语言调用汇编函数

需要在汇编代码中声明全局符号（函数或变量）。

```asm
.global compare_data
```

C 代码中用 extern 声明函数。

```c
extern int compare_data(int a, int b);
```

2. GCC 内联汇编

GCC 内联汇编语法格式：

```c
asm("assembly code" : output : input : clobber);
```

其中：
- assembly code：嵌入的汇编代码
- output：输出操作数（寄存器或变量）
- input：输入操作数（寄存器或变量）
- clobber：被内联汇编修改、需要告知编译器的寄存器或状态

“输入”是 C 代码传递给汇编代码的数据。
“输出”是汇编代码传递给 C 代码的数据。
内联汇编中的 %0、%1 等符号对应约束中指定的操作数编号，编号从 output 开始。

3. 混合编程编译方法

```bash
gcc asm_code.s c_code.c -o exefile
```
